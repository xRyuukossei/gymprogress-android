# Prévias de design

Arquivos HTML locais para comparar ideias e escolher cores. Não são parte do APK e não
representam necessariamente o estado atual do app: algumas propostas foram aprovadas e
outras foram revertidas durante a conversa.

- `tema-preview.html`: laboratório de cores; exporta/importa JSON de paleta.
- `comparacao-visual.html`: propostas iniciais, incluindo tela separada de descanso que foi
  posteriormente descartada. A evolução no histórico também foi adiada para a v2.
- `proposta-proxima-etapa.html`: Início, organização, sincronização e usabilidade. A organização
  de Treinos foi revertida e não está ativa no app.

Use esses arquivos como referências de design; o código Kotlin é a fonte do comportamento
implementado. Não inserir tokens ou dados reais de usuários nas demonstrações.
